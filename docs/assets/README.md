# Partuno assets

This directory contains reusable branding and demonstration assets.

- `partuno-logo.png` is the full-resolution project logo.
- `partuno-plugin-icon.png` is a compact PNG for client or plugin upload fields
  with strict file-size limits.
- Future screen recordings should be short, sanitized demonstrations of the
  deployed user experience. Prefer descriptive names such as
  `featured-recommendation.gif` and keep private source videos outside the
  repository unless they are intentionally published.

Do not add API keys, OAuth codes, bearer tokens, private URLs, customer data,
account identifiers, or reusable mutation tokens to this directory.
